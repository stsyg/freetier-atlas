# FreeTier Atlas URL host allowlist.
#
# Consumed by scripts/check_urls.py. Every http:// or https:// URL in a tracked
# file must resolve to a host listed here, or the check fails.
#
# This is deliberately an ALLOWLIST, never a denylist. A denylist would require
# committing the very hostnames we are trying to keep out of a public repository,
# which would re-disclose them. If you need a new host, add it here in a reviewed
# commit and say why.
#
# Format
#   host.example.org   exact host match
#   .example.org       suffix rule: matches the domain itself and any subdomain
#   # comment          ignored
#
# Ports, userinfo and trailing dots are stripped before matching, and matching is
# case-insensitive, so list bare lowercase hostnames only.
#
# Operational note: package-lock.json funding URLs are in scope, so a dependency
# bump can introduce a new host and fail this check. That is intended - the new
# host gets a human look before it lands.

# internal host can hide beneath them.
